# personality-type-database-cogfunctions

An app where you can contribute and lookup accurate type information of the human race. 

As type theory (cognitive function theory, aka. MBTI) becomes more popular I think people will want to know what other people are. I hope this can be universal database for accurate personality type information. This database will focus only on cognitive function theory. 

There are two other companies building similar products. The first is "Personality Database", a  database covering multiple personality systems (MBTI, Big 5, Enneagram) of famous people where users can vote for what type they think they are. The other is Boo which does the same thing. They have tried to expand into a social media app and even ventured as far as trying to become a dating app but with limited success. From my experience as a user I think there is much to improve.

My focus is as follows. the people in the database to be the everyday person rather than celebrities. There is much more value to be had knowing your friend's type compared to knowing Justin Beiber's type. This tool could potentially serve as a conduit for raising awareness about type at a grassroots level. In this process, I am optimising for accuracy. 

To begin with I will work on creating a simple UI where a user can enter a person and their associated MBTI. This will then be saved to a personal database which can be shared if the user wants to with others. This may just be useful to me as I would like to collaborate with the people I know to type the people we know! But I hope this use case may be useful to others too.
